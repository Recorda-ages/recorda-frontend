# Generated API clients

Este diretorio esta reservado para codigo gerado a partir do `openapi.json` do
backend FastAPI.

Regras:

- nao edite arquivos gerados manualmente;
- nao coloque regras de negocio aqui;
- adapte respostas da API dentro das features ou em services escritos a mao;
- configure o generator quando o backend publicar o contrato OpenAPI.
