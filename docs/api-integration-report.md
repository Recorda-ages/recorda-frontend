O ambiente de desenvolvimento usa `docker compose up -d --build` e `docker compose exec -T api python scripts/seed.py` no backend. As migrations foram aplicadas pelo entrypoint e o seed criou as contas comuns e administrativa. O Compose fornece um segredo de sessão estável para desenvolvimento. Nenhum volume existente foi apagado.

O Metro foi iniciado na porta 8082, pois a 8081 estava ocupada pelo Docker. Foi usado `EXPO_PUBLIC_API_URL=http://127.0.0.1:8000`. Para um emulador Android padrão, usar `http://10.0.2.2:8000`; para aparelhos físicos, configurar o endereço LAN do computador e verificar o acesso à porta 8000. Essas duas formas de acesso não foram executadas neste ambiente.

Os Pods iOS locais estavam desatualizados e não continham o módulo ExpoAudio já declarado no projeto. `npx pod-install ios` seguido de recompilação corrigiu a inicialização. O diretório iOS gerado é ignorado pelo Git; a atualização dos Pods deve ser repetida em outro checkout quando necessário.

O encerramento pendente do Jest tinha duas causas: o timeout de preload permanecia ativo após as imagens carregarem e alguns clientes de teste agendavam coleta de queries/mutações por cinco minutos após a desmontagem. O preload agora limpa seu timer em `finally`. Os clientes de teste usam tempos de coleta explícitos e a limpeza global desmonta componentes antes de limpar o cache da aplicação. O teste de regressão do preload falhou antes da correção e passou depois. Não foi adicionado `forceExit`.
